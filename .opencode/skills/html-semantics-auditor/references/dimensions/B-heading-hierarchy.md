# B — 标题层级

标题是页面的"大纲"，屏阅器用标题导航。层级混乱直接破坏可访问性。

## 检查项

### B1. 每页有且仅有一个 `<h1>`
- ✅ 一个 `<h1>` 作为页面主标题
- ❌ 无 `<h1>`（屏阅找不到页面入口）
- ❌ 多个 `<h1>`（大纲混乱）

### B2. 标题层级不跳级
- ✅ `h1 → h2 → h3`，逐级递进
- ❌ `h1 → h3`（跳过 h2，屏阅大纲断裂）
- ❌ `h2 → h4`（跳过 h3）
- ⚠️ 跳级是大纲最常见问题

### B3. 不为样式用标题
- ❌ 用 `<h3>` 只为"大字号"，而非层级关系
- ✅ 字号用 CSS `font-size`，层级用语义标题

### B4. 标题文本非空、跨级不重复
- ❌ 空 `<h2></h2>`
- ⚠️ 同级多个标题文本完全相同

### B5. 标题不嵌套在非内容容器中作布局
- ⚠️ 标题被塞进 `<div class="card">` 仅作视觉，无层级上下文

## LLM 核对项
- 单页 h1 数量：0 个或多于 1 个均不合规
- 相邻标题是否跳级（h_prev → h_cur，cur > prev+1 即跳级，如 h1→h3）
- 标题是否仅为样式而用（非层级关系）
- 标题文本是否为空或跨级重复

## 正反例
```html
<!-- ✅ -->
<main>
  <h1>openEuler 社区</h1>
  <h2>简介</h2>
  <h2>SIG 列表</h2>
  <h3>Kernel SIG</h3>
</main>

<!-- ❌ 跳级 -->
<h1>openEuler 社区</h1>
<h3>简介</h3>   <!-- h1→h3 跳过 h2 -->
```
