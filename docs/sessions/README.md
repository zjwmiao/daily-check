# 会话日志

> 每个文件对应一次工作会话。Claude 在每轮结束时追加一行摘要;关键决策同步写入 `../decisions.md`。

## 命名

`YYYY-MM-DD-<主题slug>.md`,例如 `2026-05-13-workflow-design.md`。

## 文件结构

```markdown
# <主题> — YYYY-MM-DD

## 目标
<1-2 句话说明本次会话要达成什么>

## 轮次

### Round 1 — HH:MM
- 请求: <用户在问什么/想做什么>
- 结论: <达成的判断或方向>
- 产出: <动了哪些文件 / 写了哪些代码 / 引用了哪条 ADR>

### Round 2 — HH:MM
...

## 未完成 / 待办
- [ ] ...
```
